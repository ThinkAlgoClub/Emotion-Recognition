# **1. Installations Required for Frontend and Backend**

In this lesson, you will set up all the tools and dependencies needed to run the Emotion Recognition project. We will prepare the backend environment (Python, Flask, TensorFlow) and the frontend environment (Node.js, React). By the end, you will have two working directory structures ready to launch the backend server and the React application.

---

### 1.1 System Requirements & Prerequisites
- **Operating System:** Windows, macOS, or Linux.
- **Python:** Version 3.8–3.11 (TensorFlow compatibility is best in this range).
- **Node.js:** Version 16 or later (includes npm).
- **Code Editor:** Visual Studio Code (recommended) for integrated terminal and project navigation.
- **Git:** Optional, for version control.

---

### 1.2 Setting Up the Backend (Python/Flask)

#### Step 1: Create the project folder
Open a terminal (or VS Code terminal) and create the root directory:
```bash
mkdir emotion-recognition-cnn
cd emotion-recognition-cnn
mkdir backend
mkdir backend/model
```

#### Step 2: Set up a Python virtual environment
Inside `backend/`, create a virtual environment to isolate dependencies:
```bash
cd backend
python -m venv venv
```
Activate it:
- **Windows (Command Prompt):** `venv\Scripts\activate`
- **Windows (PowerShell):** `.\venv\Scripts\Activate.ps1`
- **macOS/Linux:** `source venv/bin/activate`

You should see `(venv)` in your terminal prompt.

#### Step 3: Install backend dependencies
Create a `requirements.txt` file inside `backend/` with the following content:

```
flask
flask-cors
tensorflow
pillow
numpy
```

Now install them:
```bash
pip install -r requirements.txt
```

*Note:* Installing TensorFlow can be done via `pip install tensorflow` (CPU version) or `tensorflow-gpu` if you have a compatible GPU and CUDA setup. For simplicity, use the CPU version unless you plan to train extensively.

**Common issues & fixes:**
- **TensorFlow installation fails:** Ensure Python version is 3.8–3.11. Use `pip install tensorflow==2.13.0` if needed.
- **Pillow errors:** On Linux, you may need to install system libraries: `sudo apt install libjpeg-dev zlib1g-dev`.
- **Long path errors on Windows:** Enable long paths in Windows settings or place the project close to the root of the drive.

### 1.3 Setting Up the Frontend (React)

#### Step 1: Install Node.js and npm
If you don’t have Node.js, download the LTS version from [nodejs.org](https://nodejs.org). Verify installation:
```bash
node --version
npm --version
```

#### Step 2: Create the React app
Navigate back to the project root and use `create-react-app`:
```bash
cd ..   # you are now in emotion-recognition-cnn/
npx create-react-app frontend
```
This will create a `frontend/` directory with all boilerplate files.

#### Step 3: Install additional React dependencies
Move into the React folder and install the required packages:
```bash
cd frontend
npm install axios react-webcam
```
- **axios:** For making HTTP POST requests to the Flask backend.
- **react-webcam:** To capture images from the user’s webcam directly in the browser.

#### Step 4: Verify the default React app runs
```bash
npm start
```
The app will open on `http://localhost:3000`. Stop it with `Ctrl+C` once verified.

### 1.6 Testing the Installations Before Coding
**Backend test:** Create a simple Flask app to check everything works.
- In `backend/`, create a file `test_app.py`:
  ```python
  from flask import Flask
  app = Flask(__name__)
  @app.route('/')
  def hello():
      return "Backend is running!"
  if __name__ == '__main__':
      app.run(debug=True)
  ```
- Run it: `python test_app.py` – visit `http://localhost:5000`. You should see the message.

**Frontend test:** Already verified with `npm start`.
